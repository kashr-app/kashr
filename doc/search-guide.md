# Search Guide

Search through transaction descriptions, counterparty names, tags, and notes. Type what you're looking for — it's that simple.

**Note:** Search doesn't cover amounts or dates (use filters for those).

## Examples

| Search Query | Finds |
|--------------|-------|
| `grocery` | Transactions containing "grocery" |
| `amazon prime` | Both "amazon" AND "prime" (in any order) |
| `groc*` | grocery, groceries, grocer (prefix match) |

## Prefix Search

Add `*` at the end of a word to match anything starting with it:
- `star*` → starbucks, starwood, start
- `coffee* shop*` → coffee/coffees + shop/shops/shopping

That's it. Just type and search.
